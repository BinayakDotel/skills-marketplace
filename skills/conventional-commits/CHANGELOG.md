# Changelog

## 1.0.0 (2026-10-04)

First release in this repo.

- Writes Conventional Commits messages (typed subject, optional body, breaking-change and issue footers) from a diff, staged changes or a short description.
- Type/scope table, subject and body rules, and worked good/bad examples.
- Advises splitting a mixed change into several focused commits.
- Pure instructions with no dependencies, so it runs in any agent that reads `SKILL.md`.
